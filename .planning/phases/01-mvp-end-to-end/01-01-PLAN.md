<objective>
Lay down the Go project skeleton and the two foundational packages that drive ingestion: `sources` (sources.yaml loader, URL templating, base64/plain auto-detection, HTTP fetching) and `xrayknife` (subprocess wrapper around the xray-knife binary, auto-install on first run).

After this plan, `vlessfilter run --stage fetch` works end-to-end: it reads sources.yaml, fetches each subscription, hands them to xray-knife's `subs add` + `subs fetch`, populating xray-knife's SQLite library at `~/.xray-knife/xray-knife.db`.

Stage 2 + selector + output formatting are handled in Plan 01-02.

Purpose: Establish the project layout and ingestion path. Every downstream phase reuses these packages.

Output:
- A buildable, runnable Go binary
- A `sources` package with unit-tested YAML parsing + URL expansion
- An `xrayknife` package with a `Runner` interface (real + fake impls) so future plans can mock the subprocess for tests
- A `sources.yaml` containing 2 default sources (v2go US country file + barry-far vless protocol file)
</objective>

  <action>
    1. Define schema in `internal/sources/sources.go`:
       ```go
       type Config struct {
           Sources []Source `yaml:"sources"`
           Countries []string `yaml:"countries,omitempty"` // for country-template expansion; defaults to ["US","DE"] in Phase 1
       }
       type Source struct {
           Name    string `yaml:"name"`
           URL     string `yaml:"url"`
           Kind    string `yaml:"kind"`     // "plain" | "country-template"
           Enabled bool   `yaml:"enabled"`
       }
       type Subscription struct {
           SourceName string  // e.g., "v2go-country/US"
           URL        string  // expanded URL
           Body       []byte  // decoded subscription text (always plain after fetch)
       }
       ```
    2. Implement `Load(path string) (*Config, error)`:
       - Read file, parse with yaml.v3.
       - Validate: each source has non-empty `name`, `url`, `kind`; `kind` is one of `plain | country-template`.
       - If `Countries` is nil, default to `["US","DE"]` (per D-04).
       - Filter out `enabled: false` entries.
    3. Implement `Expand(cfg *Config) []ExpandedSource`:
       - For `kind: plain` → emit one `ExpandedSource{Name, URL}`.
       - For `kind: country-template` → for each `cc` in `cfg.Countries`, emit `ExpandedSource{Name: src.Name + "/" + cc, URL: strings.ReplaceAll(src.URL, "{CC}", cc)}`.
    4. Implement `Fetch(ctx context.Context, src ExpandedSource) (Subscription, error)` using `net/http`:
       - 30s timeout
       - User-Agent: `"vlessfilter/0.1 (+https://github.com/<user>/vlessfilter)"`
       - On 200 OK: read body, run `decodeBody(body) ([]byte, error)`:
         - Try `base64.StdEncoding.DecodeString(strings.TrimSpace(string(body)))`. If err is nil AND result contains substring `"vless://"`, return decoded.
         - Else return body as-is (plain text).
       - On non-200: return error wrapping status code.
    5. Write `internal/sources/sources_test.go` with:

       - `TestLoad_DefaultsCountries` — yaml without `countries:` field defaults to `["US","DE"]`.
       - `TestLoad_RejectsBadKind` — yaml with `kind: bogus` returns error.
       - `TestExpand_CountryTemplate` — `kind: country-template` with `{CC}` and 3 countries produces 3 expansions with substituted URLs.
       - `TestDecodeBody_Base64` — feed `testdata/sample-base64.txt` (a base64-encoded vless URI), assert decoded result contains `"vless://"`.
       - `TestDecodeBody_Plain` — feed `testdata/sample-plain.txt` (plain vless URI), assert returned bytes are unchanged.
    6. Create `testdata/sample-plain.txt` with one fake vless URI: `vless://00000000-0000-0000-0000-000000000000@example.com:443?type=tcp&security=reality#fake-test-key`

  <action>
    1. Define `Runner` interface in `internal/xrayknife/xrayknife.go`:
       ```go
       type Runner interface {
           Available(ctx context.Context) (bool, error)            // checks `xray-knife --version`
           Install(ctx context.Context) error                      // `go install github.com/lilendian0x00/xray-knife/v9@<PIN>`
           SubsAdd(ctx context.Context, url, remark string) error  // `xray-knife subs add --url URL --remark NAME`
           SubsFetch(ctx context.Context) error                    // `xray-knife subs fetch` (all subs)
           HTTPTest(ctx context.Context, opts HTTPOpts) error      // `xray-knife http --from-db --protocol vless [--speedtest] -t N`
           DBPath() (string, error)                                // returns ~/.xray-knife/xray-knife.db
       }
       type HTTPOpts struct {
           Speedtest bool
           Threads   int   // -t flag
           Limit     int   // --limit flag (0 = no limit)
           Protocol  string // default "vless"
       }
       ```
    2. Implement `RealRunner` (default impl) using `os/exec`:
       - `Available`: run `exec.CommandContext(ctx, "xray-knife", "--version")`, parse stdout, return `true` if successful and stdout contains a semver-like string.
       - `Install`: run `exec.CommandContext(ctx, "go", "install", "github.com/lilendian0x00/xray-knife/v9@latest")`. (Pin the version in a const `XrayKnifeVersion = "latest"` for now; Phase 2 swaps in a specific tag once we verify compatibility.)
       - `SubsAdd`: `exec.CommandContext(ctx, "xray-knife", "subs", "add", "--url", url, "--remark", remark)`. Idempotency: if stderr/stdout contains `"already exists"` or `"duplicate"` substring, return nil (not an error). Stream stdout to slog.Debug.
       - `SubsFetch`: `exec.CommandContext(ctx, "xray-knife", "subs", "fetch")`. Stream stdout to slog.Info (this can take 10-30s).
       - `HTTPTest`: build args from `HTTPOpts`. Always pass `--from-db --protocol <proto>`. Add `--speedtest` if opts.Speedtest. Add `-t <n>` if opts.Threads > 0. Add `--limit <n>` if opts.Limit > 0.
       - `DBPath`: returns `filepath.Join(os.Getenv("HOME"), ".xray-knife", "xray-knife.db")` (Linux only; darwin same path; Windows we don't support in Phase 1 but TODO comment).
    3. Implement `EnsureInstalled(ctx context.Context, r Runner) error`:
       - Call `r.Available(ctx)`. If true, return nil.
       - Else log `slog.Info("xray-knife not found — installing via go install...")`, call `r.Install(ctx)`. On success, call `r.Available(ctx)` again to verify and return nil; on still-not-available, return error `"xray-knife installation succeeded but binary not found on PATH; ensure $GOPATH/bin or $GOBIN is on PATH"`.
       - Pre-flight: if `exec.LookPath("go")` fails, return error `"go binary not found on PATH; install Go 1.22+ from https://go.dev"`. Skip this check if Available returned true (Go isn't needed if xray-knife is already installed).
    4. Implement `FakeRunner` for tests in same file (or `xrayknife_test.go`):
       - Tracks calls in slices: `Calls []string` (e.g., "subs add v2go US https://...").
       - `Available` returns the value of a configurable field `IsAvailable bool`.
       - `Install` sets `IsAvailable = true` and records the call.
       - `SubsAdd` / `SubsFetch` / `HTTPTest` record args and return nil (or a configurable error).
    5. Write tests in `internal/xrayknife/xrayknife_test.go`:
       - `TestEnsureInstalled_AlreadyAvailable` — FakeRunner with `IsAvailable: true`, EnsureInstalled returns nil, Install was NOT called.
       - `TestEnsureInstalled_InstallsIfMissing` — FakeRunner starting `IsAvailable: false`, after EnsureInstalled the runner's Calls contains "Install" and IsAvailable is true.
       - `TestEnsureInstalled_FailsIfStillMissing` — FakeRunner where Install doesn't flip IsAvailable, EnsureInstalled returns an error mentioning "PATH".
       - `TestSubsAdd_IgnoresDuplicate` — RealRunner alternative: provide a stubbed exec that returns "already exists" on stderr; assert no error returned. (If full exec stubbing is too heavy, mark this as `// TODO Phase 2: integration test` and just doc the behavior.)
    6. Wire `cmd/vlessfilter/main.go` `run --stage fetch` path:
       - Load sources via `sources.Load(*sourcesPath)`.
       - Expand to `[]ExpandedSource`.
       - Construct `xrayknife.RealRunner{}`, call `EnsureInstalled`.
       - For each expanded source: call `runner.SubsAdd(ctx, src.URL, src.Name)` (skip if base64-decode would be needed — at this layer we delegate to xray-knife since it handles both formats).
       - Call `runner.SubsFetch(ctx)` to populate the DB.
       - On --stage flag values other than `fetch`, print "stage X not yet implemented (Plan 01-02)" and exit 0 for now.
       - Print final line `slog.Info("fetch complete", "subscriptions", N, "db", dbPath)`.
  </action>
