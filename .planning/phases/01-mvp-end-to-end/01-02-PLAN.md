<objective>
Read xray-knife's SQLite results database, score each tested key with the composite formula (D-06), group by exit-IP country, pick top 3 per country, and write per-country subscription files plus a README summary table. Then orchestrate the full pipeline end-to-end through `cmd/vlessfilter`.

After this plan, `vlessfilter run` works as a complete happy path on Linux: read sources.yaml → fetch subs → run handshake stage → run speedtest stage → write outputs.

Purpose: Close the loop from "ingestion done" (Plan 01-01) to "user can paste subs/US.txt into Hiddify and connect". Phase 1's MVP exit criteria.

Output:

    3. Implement `Score(r Result) float64` in `selector.go`:
       ```go
       const (
           MaxLatencyMs = 1000.0
           MaxSpeedMbps = 100.0
           WSpeed       = 0.6
           WLatency     = 0.4
       )
       func Score(r Result) float64 {
           normSpeed := math.Min(r.SpeedMbps, MaxSpeedMbps) / MaxSpeedMbps
           normLatency := math.Min(float64(r.LatencyMs), MaxLatencyMs) / MaxLatencyMs
           return WSpeed*normSpeed - WLatency*normLatency
       }
       ```
    4. Implement `Top3PerCountry(results []Result) []CountrySelection`:

       - Group by `Country` (skip empty-country rows — they're omitted per D-07).

       - Take first up to 3 (countries with <3 alive keys still emit partial — D-07).
       - Return slice of CountrySelections sorted by Country code asc (D-08).
